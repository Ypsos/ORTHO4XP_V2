# Code de Conduite / Code of Conduct

## Notre engagement / Our Pledge

Nous nous engageons à faire de ce projet un espace ouvert et accueillant pour tous.  
We are committed to making this project an open and welcoming space for everyone.

## Comportements attendus / Expected Behavior

- Être respectueux et bienveillant  
  Be respectful and kind
- Accepter les critiques constructives  
  Accept constructive criticism
- Se concentrer sur ce qui est le mieux pour le projet  
  Focus on what is best for the project

## Comportements inacceptables / Unacceptable Behavior

- Insultes, harcèlement ou discrimination  
  Insults, harassment or discrimination
- Commentaires agressifs ou trolls  
  Aggressive comments or trolling
- Publication d’informations privées d’autrui  
  Publishing others’ private information

## Application / Enforcement

Les mainteneurs du projet se réservent le droit de supprimer, éditer ou rejeter les commentaires, commits, issues ou pull requests qui ne respectent pas ce code de conduite.  
Project maintainers reserve the right to remove, edit, or reject comments, commits, issues, or pull requests that do not follow this Code of Conduct.

## Contact

Pour signaler un problème : ouvrez une Issue ou contactez le mainteneur du dépôt.  
To report an issue: open an Issue or contact the repository maintainer.
