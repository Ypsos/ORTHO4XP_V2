# Comment contribuer / How to Contribute

Merci de vouloir contribuer à ORTHO4XP_V3 !  
Thank you for wanting to contribute to ORTHO4XP_V3!

## Signaler un bug / Reporting a Bug

1. Vérifiez d’abord que le bug n’a pas déjà été signalé.  
   First check that the bug has not already been reported.
2. Ouvrez une **Issue** en décrivant clairement :  
   Open an **Issue** clearly describing:
   - Ce que vous faisiez / What you were doing
   - Ce qui s’est passé / What happened
   - Ce qui aurait dû se passer / What should have happened
   - Votre système (Windows / macOS / Linux) et version d’Ortho4XP  
     Your system (Windows / macOS / Linux) and Ortho4XP version

## Proposer une amélioration / Suggesting an Improvement

Ouvrez une Issue en expliquant votre idée.  
Open an Issue explaining your idea.

## Proposer du code (Pull Request) / Submitting Code (Pull Request)

1. Forkez le dépôt / Fork the repository
2. Créez une branche / Create a branch
3. Faites vos modifications / Make your changes
4. Ouvrez une Pull Request en expliquant clairement ce que vous avez changé  
   Open a Pull Request clearly explaining what you changed

## Style de code / Code Style

Essayez de rester cohérent avec le style déjà présent dans le projet.  
Try to stay consistent with the existing code style of the project.
