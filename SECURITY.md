# Politique de sécurité / Security Policy

## Signalement d’une vulnérabilité / Reporting a Vulnerability

Si vous découvrez une faille de sécurité dans ORTHO4XP_V3, merci de **ne pas** l’ouvrir en Issue publique.  
If you discover a security vulnerability in ORTHO4XP_V3, please **do not** open a public Issue.

Contactez plutôt le mainteneur du dépôt de façon privée.  
Please contact the repository maintainer privately instead.

Nous vous répondrons dans les meilleurs délais.  
We will respond as soon as possible.
